Read an integer **N**, then read **N** integers. Print how many of them are **even**.

### Input

- First line: an integer `N` (1 <= N <= 2·10^4)
- The next `N` lines: one integer per line (-10^9 <= x <= 10^9)

### Output

A single integer: the count of even numbers.

### Examples

```
Input:
5
1
2
3
4
5
Output: 2
```

```
Input:
4
2
4
6
8
Output: 4
```

```
Input:
3
1
3
5
Output: 0
```

When none of the numbers are even, the count stays at 0. Still print it.
