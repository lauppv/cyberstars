Given a single line of text, print it **reversed**.

### Input

A single line containing a string `s` of 1 to 10^5 ASCII characters (letters, digits, spaces and punctuation). Spaces can appear anywhere, including several in a row or at the start or end of the line, and they are reversed like any other character.

### Output

The string `s` written backwards, on a single line.

### Examples

```
Input:  hello
Output: olleh
```

```
Input:  CyberStars
Output: sratSrebyC
```

```
Input:  a
Output: a
```

A single character reversed is itself.

```
Input:  noon
Output: noon
```

Some strings look the same reversed. That's a coincidence of their letters,
not a special case your code needs to detect.
