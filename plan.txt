CYBERSTARS — PLAN CURRICULA (v1)
==================================

Stare curenta:
- Python: 18 lectii (bazele de la zero: print, variabile, if, for, while, functii, liste)
- Java: 17 lectii (aceleasi baze ca Python, dar in Java)
- C: 16 lectii (aceleasi baze ca Python, dar in C)
- Algo: 6 probleme LeetCode-style (separate)

Problema: toate cele 3 curricula predau aceleasi lucruri de la zero. Nu exista diferentiere.

================================================================================
NOUA STRUCTURA (~50 lectii per curricula)
================================================================================

1. PYTHON — "Bazele programarii + algoritmica de baza"
   Target: incepatori absoluti, prima limba de programare
   ~50 lectii

   Bloc A: Bazele (lectiile 1-25 aprox)
   - Ce e programarea, cum gandesti ca un programator
   - Print, variabile (str, int, float), tipuri de date
   - Input de la utilizator
   - Operatori (aritmetici, comparatie, logici)
   - If / elif / else
   - While, for, range()
   - Functii (def, parametri, return)
   - Strings (indexare, slicing, metode)
   - Liste (creare, append, remove, iterare, list comprehension)
   - Dictionare (key-value, iterare, metode)
   - Tuple, seturi
   - Nested loops, nested structures
   - Fisiere (citire/scriere de baza)
   - Exceptii (try/except de baza)
   - Functii utile built-in (len, sorted, min, max, sum, enumerate, zip, map, filter)

   Bloc B: Algoritmica de baza — cum transpui o idee in cod (lectiile 26-50 aprox)
   - Cum descompui o problema in pasi
   - Pattern-uri de baza: counter, accumulator, flag
   - Cautare liniara
   - Sortare (bubble sort, selection sort — intelegerea conceptuala)
   - Strings: reverse, palindrom, anagrame, numarare caractere
   - Liste: filtrare, transformare, gasire max/min custom
   - Frecvente cu dictionare (histograma, moda)
   - Two pointers (de baza)
   - Recursie (introducere)
   - Mini-proiecte (joc de ghicit, quiz, gestionar de task-uri CLI)


2. JAVA — "OOP core + algoritmica in context OOP"
   Target: deja stiu bazele programarii (din Python)
   NU mai invatam ce e o variabila de la zero — invatam ce e DIFERIT in Java
   ~50 lectii

   Bloc A: Java-specific — tranzitie de la Python (lectiile 1-15 aprox)
   - Diferente cheie: compilare vs interpretare, tipuri statice, main()
   - Declarare variabile cu tip (int, double, String, boolean) — erori de compilare
   - System.out.println vs print()
   - Casting explicit/implicit
   - Arrays (dimensiune fixa vs liste din Python)
   - Scanner (input)
   - Strings in Java (immutable, .equals() vs ==, metode)
   - Functii utile (Math.*, Arrays.*, String.format)

   Bloc B: OOP Core (lectiile 16-35 aprox)
   - Ce e OOP si de ce exista
   - Clase si obiecte
   - Atribute si metode
   - Constructori
   - this
   - Encapsulare (private, getteri, setteri)
   - Static vs non-static
   - Mostenire (extends)
   - Polimorfism (override)
   - Clase abstracte
   - Interfete (implements)
   - ArrayList, HashMap (colectii de baza)
   - Exceptii (try/catch/throw)
   - Enum-uri

   Bloc C: Algoritmica in context OOP (lectiile 36-50 aprox)
   - Exercitii care combina OOP + algoritmi
   - Implementare stack/queue cu clase
   - Linked list simplu (clasa Node)
   - Sortari implementate in clase
   - Comparator / Comparable
   - Mini-proiecte OOP (sistem de gestiune studenti, inventar, etc.)


3. C — "Low-level programming + Linux"
   Target: inteleg programarea, vreau sa inteleg ce e sub capota
   ~50 lectii

   Bloc A: C fundamentals — ce e diferit (lectiile 1-15 aprox)
   - Compilare (gcc), ce e un executabil
   - printf / scanf
   - Tipuri de date si dimensiuni (sizeof)
   - Pointeri (adrese, dereferentiere)
   - Arrays si pointeri (legatura intre ele)
   - Strings ca arrays de char (null terminator)
   - Alocare dinamica (malloc, free)
   - Structuri (struct)
   - Functii (pass by value vs pass by pointer)
   - Fisiere (fopen, fread, fwrite)
   - Preprocesorul (#include, #define, header files)
   - Functii utile (string.h, stdlib.h, stdio.h)

   Bloc B: Algoritmi de baza in C (lectiile 16-30 aprox)
   - Sortari (bubble, selection, insertion — implementate cu pointeri)
   - Cautare binara
   - Linked list (implementare manuala cu malloc)
   - Stack si queue (implementare cu array/linked list)
   - Recursie in C
   - Manipulare de biti (bitwise operators)
   - Matrice (alocare dinamica 2D)

   Bloc C: Linux & system programming (lectiile 31-50 aprox)
   - Introducere in terminal Linux (ls, cd, cat, grep, chmod)
   - Procese (fork, exec, wait)
   - Pipes (| in shell, pipe() in C)
   - Redirectare I/O
   - Semnale (signal, kill)
   - Scripting bash de baza
   - Makefile
   - Compilare cu mai multe fisiere
   - Debugging (gdb basics, valgrind)
   - Mini-proiecte (shell simplu, pipe intre procese, tool CLI)

   Nota: pentru bloc C vom avea nevoie de un terminal integrat in platforma
   (probabil un container/sandbox) in care utilizatorul sa poata rula comenzi Linux.
   Asta e o feature separata, de implementat mai tarziu.

ORDINE DE IMPLEMENTARE SUGERATA
================================================================================

2. Java — rescriem curriculumul cu focusul pe OOP. ~50 lectii.
3. C — rescriem cu focusul pe low-level + Linux. ~50 lectii.
   (terminalul Linux integrat e o dependenta pentru Bloc C din C)

Per lectie avem nevoie de:
- Continut teoretic (markdown/HTML)
- Cod initial (starter code)
- Teste / validare (expected output sau test cases)
- (Optional) hints
