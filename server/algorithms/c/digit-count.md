# Easy · Count Digits

Read a single integer and print how many **digits** it has.

### Input

- A single integer `N` (0 ≤ N ≤ 1 000 000 000)

### Output

A single integer: the number of digits in `N`.

### Examples

```
Input:
12345
Output: 5
```

```
Input:
0
Output: 1
```

```
Input:
7
Output: 1
```

```
Input:
1000000000
Output: 10
```
