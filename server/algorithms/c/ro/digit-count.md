Citește un singur număr întreg și afișează câte **cifre** are.

### Date de intrare

- Un singur întreg `N` (0 ≤ N ≤ 1 000 000 000)

### Rezultat

Un singur întreg: numărul de cifre din `N`.

### Exemple

```
Intrare:
12345
Ieșire: 5
```

```
Intrare:
0
Ieșire: 1
```

```
Intrare:
7
Ieșire: 1
```

```
Intrare:
1000000000
Ieșire: 10
```
