Citește un întreg **N** și afișează un triunghi aliniat la stânga format din caractere `*`. Linia 1 are 1 stea, linia 2 are 2 stele și așa mai departe până la linia N.

### Date de intrare

- Un singur întreg `N` (1 ≤ N ≤ 20)

### Rezultat

`N` linii. Linia `i` (începând de la 1) conține exact `i` asteriscuri (`*`), fără spații la final.

### Exemple

```
Intrare:
3
Ieșire:
*
**
***
```

```
Intrare:
5
Ieșire:
*
**
***
****
*****
```

```
Intrare:
1
Ieșire:
*
```

Cel mai mic caz: un singur rând cu o singură stea.
