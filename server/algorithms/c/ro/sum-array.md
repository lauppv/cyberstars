Citește un întreg **N**, apoi citește **N** numere întregi. Afișează **suma** lor.

### Date de intrare

- Prima linie: un întreg `N` (1 <= N <= 2·10^4)
- Următoarele `N` linii: câte un număr întreg (-10^7 <= x <= 10^7)
- Suma, la fel ca orice sumă parțială pe parcurs, încape într-un `int` (-2·10^9 <= suma <= 2·10^9)

### Rezultat

Un singur întreg: suma tuturor celor `N` numere.

### Exemple

```
Intrare:
5
1
2
3
4
5
Ieșire: 15
```

```
Intrare:
3
10
-3
7
Ieșire: 14
```

```
Intrare:
1
7
Ieșire: 7
```

```
Intrare:
3
-1
-2
-3
Ieșire: -6
```
