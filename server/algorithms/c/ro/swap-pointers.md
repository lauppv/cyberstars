Citește două numere întregi. Scrie o funcție `interschimba` care primește doi **pointeri la int** și interschimbă valorile lor. Apeleaz-o din `main`, apoi afișează valorile interschimbate.

### Date de intrare

- Linia 1: primul număr întreg
- Linia 2: al doilea număr întreg

### Rezultat

Cele două numere întregi interschimbate, separate prin spații, pe o singură linie.

### Exemple

```
Intrare:
3
7
Ieșire: 7 3
```

```
Intrare:
10
10
Ieșire: 10 10
```

```
Intrare:
-3
8
Ieșire: 8 -3
```

Numerele negative se interschimbă prin pointeri la fel ca orice altă valoare.
