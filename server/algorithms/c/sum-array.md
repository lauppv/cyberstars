Read an integer **N**, then read **N** integers. Print their **sum**.

### Input

- First line: an integer `N` (1 ≤ N ≤ 100)
- The next `N` lines: one integer per line

### Output

A single integer: the sum of all `N` numbers.

### Examples

```
Input:
5
1
2
3
4
5
Output: 15
```

```
Input:
3
10
-3
7
Output: 14
```

```
Input:
1
7
Output: 7
```

```
Input:
3
-1
-2
-3
Output: -6
```
