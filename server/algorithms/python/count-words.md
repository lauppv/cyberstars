# Count Words

Given a sentence, count how many **words** it contains.

### Input

A single line containing a sentence of words separated by spaces.

### Output

Print the number of words in the sentence.

### Examples

```
Input:  hello world
Output: 2
```

```
Input:  Python is really fun
Output: 4
```

```
Input:  hello
Output: 1
```

A single word is still one word.
