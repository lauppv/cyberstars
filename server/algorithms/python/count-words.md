# Count Words

Given a sentence, count how many **words** it contains.

### Input

A single line containing a sentence of words separated by spaces.

### Output

Print the number of words in the sentence.

### Examples

```
Input:  hello world
Output: 2
```

```
Input:  Python is really fun
Output: 4
```

### Hints

- The `split()` method breaks a string into a list of words.
- Use `len()` to get the length of a list.
- `split()` with no arguments handles multiple spaces correctly.
