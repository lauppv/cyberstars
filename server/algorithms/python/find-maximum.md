# Find Maximum

Given a list of numbers, find and print the **largest** one.

### Input

- Line 1: an integer `n` — the count of numbers.
- Line 2: `n` integers separated by spaces.

### Output

The largest number in the list.

### Examples

```
Input:
5
3 1 7 2 5

Output:
7
```

```
Input:
3
-10 -3 -7

Output:
-3
```

```
Input:
1
42

Output:
42
```

With a single number, that number is automatically the maximum.

```
Input:
4
5 5 5 5

Output:
5
```
