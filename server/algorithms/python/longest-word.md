Given a sentence, find and print the **longest word**.

### Input

A single line of 1 to 1000 ASCII characters containing a sentence with at least one word. A word is any sequence of characters without spaces (letters, digits or punctuation). Words are separated by one or more spaces, and the line may start or end with spaces.

### Output

Print the longest word in the sentence. If there is a tie, print the one that appears first.

### Examples

```
Input:  I love programming
Output: programming
```

```
Input:  The quick brown fox
Output: quick
```

```
Input:  cat bat rat
Output: cat
```

All three words are the same length, so it's a tie: print the one that
appears **first**.

```
Input:  hi
Output: hi
```
