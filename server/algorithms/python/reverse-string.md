# Reverse a String

Given a single line of text, print it **reversed**.

### Input
A single line containing a string `s`.

### Output
The string `s` written backwards, on a single line.

### Examples

```
Input:  hello
Output: olleh
```

```
Input:  CyberStars
Output: sratSrebyC
```

### Hints
- Strings support slicing — `s[::-1]` reverses a string in one step.
- You can also build the reversed string with a `for` loop going backwards.
- Don't forget to `print()` the result!
