# Numără vocalele

Având un șir, numără câte **vocale** conține.

### Date de intrare

O singură linie care conține un șir `s`.

### Rezultat

Un singur număr întreg — numărul de vocale (`a`, `e`, `i`, `o`, `u`, fără a ține cont de litere mari/mici) din `s`.

### Exemple

```
Intrare:  hello
Ieșire: 2
```

```
Intrare:  Python
Ieșire: 1
```

```
Intrare:  AEIOU
Ieșire: 5
```

```
Intrare:  xyz
Ieșire: 0
```

Fără nicio vocală e un caz valid — numărul este pur și simplu `0`.
