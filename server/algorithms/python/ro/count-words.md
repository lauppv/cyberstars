# Count Words

Având o propoziție, numără câte **cuvinte** conține.

### Date de intrare

O singură linie care conține o propoziție de cuvinte separate prin spații.

### Rezultat

Afișează numărul de cuvinte din propoziție.

### Exemple

```
Intrare:  hello world
Ieșire: 2
```

```
Intrare:  Python is really fun
Ieșire: 4
```

### Indicii

- Metoda `split()` împarte un șir într-o listă de cuvinte.
- Folosește `len()` pentru a obține lungimea unei liste.
- `split()` fără argumente tratează corect spațiile multiple.
