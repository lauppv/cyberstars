# Suma cifrelor

Având un număr întreg, afișează **suma cifrelor sale**.

### Date de intrare

O singură linie care conține un număr întreg `n` (poate fi negativ).

### Rezultat

Suma cifrelor lui `n`. Dacă `n` este negativ, ignoră semnul minus.

### Exemple

```
Intrare:  1234
Ieșire: 10
```

```
Intrare:  -56
Ieșire: 11
```

```
Intrare:  0
Ieșire: 0
```

```
Intrare:  100
Ieșire: 1
```

Zerourile din `100` nu adaugă nimic la sumă — doar `1` contează.
