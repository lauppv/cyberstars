## Mission: The Magnetic Tape Reel Courier

A van transports magnetic tape reels between two computing centers. The shift operator has to calculate how much fuel the trip consumes and how much it costs, before approving the shipment.

- Read three numbers from the input, in this order: **distance_km** (whole number), **consumption_per_km** (real number, liters per km), and **price_per_liter** (real number)
- Calculate the **total fuel** needed (**distance_km \* consumption_per_km**) — put a **comment** above this calculation
- Calculate the **total cost** (**total fuel \* price_per_liter**) — put a **comment** above this calculation
- Print the three values, each on its own line, rounded to **2 decimals** where relevant

**Example**

Input

```text
450 0.07 1.75
```

Output

```text
Distance: 450 km
Fuel: 31.50 liters
Cost: 55.13 EUR
```

**Example**

Input

```text
100 0.05 1.50
```

Output

```text
Distance: 100 km
Fuel: 5.00 liters
Cost: 7.50 EUR
```
