

C is a **programming language**. It is the **foundation** of the software world. Almost all modern programming languages are **built on C**. If you understand **C**, learning any other modern programming language becomes much easier.

For example, if you know **C**, picking up **Python** is straightforward. The reverse isn’t true: if you start with **Python**, learning **C**, **C++**, **Java**, and other languages can be quite challenging. That’s why we chose to start with **C**.

---

The first thing we will learn is: **what is a variable?**  


A **variable** is something that **stores a value**. Think of it like this: everyone knows that **2 apples plus 4 pears equals 6 fruits in total**. In **C**, we can represent it like this:

```c
#include <stdio.h>

int main() {

    int apples = 2;
    int pears = 4;

    int fruits = apples + pears;

}
```

Ignore *#include*, *int main()*, and the other parts. Here we have 3 variables: **apples**, **pears**, and **fruits**. These are their **names**.
