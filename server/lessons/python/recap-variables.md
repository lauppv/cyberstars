Time to combine what you've learned! No new theory — just a challenge that uses **print**, **variables**, **f-strings**, and **comments**

---

Build a **character profile card** for a game. Create these variables:

- **name** = "Shadow" (string)
- **level** = 42 (integer)
- **health** = 97.5 (float)
- **guild** = "CyberStars" (string)

Print the profile card using **f-strings** like this. Add a **comment** above the print explaining what it does

Expected output

```text
=== PLAYER CARD ===
Name: Shadow
Level: 42
Health: 97.5 HP
Guild: CyberStars
===================
```
