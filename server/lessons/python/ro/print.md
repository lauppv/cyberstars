Python e cel mai bun limbaj de programare cu care să începi să înveți programare. Cel mai important lucru este să înțelegi **conceptele software**.  
Primul concept este **afișarea rezultatului**, sau, în „termeni ingineri", **print** :D

Cum îi spunem calculatorului „salut, îmi place pizza"? În Python scriem:

```py
print("salut, îmi place pizza")
```

Apropo, poți **rula** aceste bucăți de cod ca să vezi rezultatul. Te **încurajăm cu tărie să modifici aceste coduri și să explorezi**, să-ți pui întrebări de genul „ce se întâmplă dacă schimb asta, sau aia, sau altceva." Rulează mereu codul și vezi ce se întâmplă. Experimentarea poate fi uneori chiar **distractivă** :)

**print()** este o funcție (vom învăța în lecțiile următoare ce este de fapt o funcție). Deocamdată, trebuie doar să știm că **print()** este o instrucțiune, modul nostru de a-i spune calculatorului: „afișează ceva"

Un lucru important de observat sunt **ghilimelele** —

```py
print(salut, îmi place pizza)
```

nu va funcționa (vom învăța mai târziu de ce). Rulează și vezi ce se întâmplă

Putem face și:

```py
print("5")
```

care va afișa 5, sau:

```py
print("Am 2 câini")
```

Din nou, nu uita ghilimelele.

## Misiune: Pornește Consola

Consola de control a stației pornește cu un banner de întâmpinare. Scrie un program care folosește **print()** ca să afișeze **exact** aceste patru linii:

```text
== CONTROL MISIUNE CYBERSTARS ==
Stație: Orion
Stare: ONLINE
Bun venit la bord, cadet!
```

Psst — nu uita **ghilimelele** :) Potrivește textul exact, linie cu linie.
